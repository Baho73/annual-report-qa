# Проверка расхождения слоёв PDF (геометрия, без модели)

**Источник:** `D:\Python\test-4a\data\yandex_annual_report_2025.pdf` — 201 страниц  
**Скрипт:** `D:\Python\test-4a\build\layer_check.py`  
**Сырые находки:** `D:\Python\test-4a\build\layer_findings.json`

Что искали:

1. Растровая картинка, накрывающая ≥30 % площади текстового блока (картинка поверх текста — декор либо подмена того, что читает человек).
2. Текст кеглем < 3.0 pt.
3. Текст с режимом отрисовки 3 (invisible — типичный OCR-слой).
4. Текст, цвет которого совпадает с фоном под ним (допуск ±12 на канал).

Каждое пересечение прямоугольников дополнительно проверено по РЕАЛЬНОМУ порядку отрисовки: `page.get_text("dict")` отдаёт блоки в порядке потока контента, поэтому индекс блока-картинки против индекса блока-текста прямо говорит, что нарисовано позже. Картинка с бОльшим индексом лежит ПОВЕРХ текста (подозрение на подмену), с меньшим — ПОД ним (плитка/подложка/декор).
